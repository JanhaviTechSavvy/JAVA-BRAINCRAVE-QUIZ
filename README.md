## 📚 About the Project

This is a **learning project** built using Java Applet and core Java libraries.

Although Java Applets are now deprecated, this project was developed to understand:
- Core Java programming concepts
- GUI development using AWT/Swing
- Event handling and user interaction

This project reflects my foundational learning in Java and my journey into software development.

## ⚠️ Note

Java Applets are deprecated in modern development. This project is maintained for educational purposes to demonstrate fundamental Java concepts.
